# Device Analyzer - Android App

This directory is scheduled for **Phase 7** implementation.

## Target Architecture (Phase 7)
- **Language**: Kotlin 2.x
- **UI Toolkit**: Jetpack Compose + Material 3
- **Local Storage**: Room / SQLite
- **Architecture**: Clean Architecture + MVI/MVVM
- **Background Tasks**: Android WorkManager & Foreground Service
- **Features**:
  - Device info (Brand, SoC, sensors, display, RAM, storage)
  - Battery health & temperature
  - Shared rule-based health scoring engine
  - PDF diagnostic export
